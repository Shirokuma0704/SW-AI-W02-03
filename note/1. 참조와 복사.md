# 참조와 복사

> 한 줄 규칙: 파이썬 컨테이너에 객체를 넣으면 값이 아니라 주소가 복사된다.

## 증상 — 이런 게 보이면 의심
- 결과의 모든 행이 똑같다
- 개수는 맞는데 내용이 전부 비어 있다

## 최소 재현 (5줄 이내)
    d = [0] * 3
    m = [d, d, d]
    m[0][0] = 99      # → [[99,0,0], [99,0,0], [99,0,0]]

## 왜 그런가 (반드시 내 문장으로)
파이썬 컨테이너에 객체를 넣으면 메모리 주소를 복사하여 복사된 곳 하나라도 수정이되면 복사한 모든값이 바뀜
