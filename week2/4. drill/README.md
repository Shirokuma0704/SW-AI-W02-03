# 손으로 짜기 드릴 ✎(❁ᴗ͈ˬᴗ͈)

`week2` 코드를 쭉 보고, **아직 한 번도 안 짜 본 것**만 골라서 만든 연습장이에요.
이미 잘하는 건 굳이 또 안 넣었어요. 오늘 밤엔 안 해본 것만 해봐요!

| 파일 | 뭐 하는 건지 | 대충 이 정도 |
|---|---|---|
| `01_linked_list_drill.py` | 연결 리스트 insert / delete / reverse | 25분 |
| `02_binary_search_drill.py` | lower_bound, upper_bound, 개수 세기, 파라메트릭 서치 | 25분 |
| `03_complexity_drill.py` | 느린 코드 빠릿하게 만들기 + 복잡도 재보기 | 20분 |

## 놀이 규칙 (๑˃ᴗ˂)ﻭ

1. **함수 본문은 비워뒀어요.** 힌트도 뼈대도 일부러 안 넣었어요.
   여기서 한 번 헤매두면 내일은 안 헤매니까요!
2. **테스트 케이스도 직접 채워요.** 파일마다 "직접 추가 (최소 3개)" 칸이 있고,
   안 채우면 통과로 안 쳐줘요. 지금 들어있는 건 전부 얌전히 잘 되는 경우라,
   **어디서 터질지 찾아내는 게 절반의 재미**예요.
3. **한 번에 한 군데만 고치고 바로 돌려요.** 여러 군데를 같이 고치면
   뭐가 원인이었는지 영영 모르게 돼요 (｡•́ - •̀｡)
4. **막히면 코드를 다시 읽지 말고 print 를 찍어요.** 특히 이분 탐색에서
   무한 루프가 나면 `left`, `right`, `mid` 를 매 반복마다 찍어보면
   1분 안에 보여요. 진짜예요!

## 돌려보기

```
.venv/Scripts/python.exe "week2/4. drill/check.py"        # 전부 한 번에
.venv/Scripts/python.exe "week2/4. drill/check.py" 01     # 하나만
```

파일 하나만 따로 실행해도 잘 돌아가요.

```
.venv/Scripts/python.exe "week2/4. drill/01_linked_list_drill.py"
```

그 입력만 들고 따라가면 돼요. 화이팅! ٩(ˊᗜˋ*)و
