### 1. 얕은복사

```
d = [0]*n
for n in range(0,n):
    r_matrix.append(d)     # ← 같은 객체를 3번 넣음
```
리스트에 객체를 넣으면 값이 아닌 주소 즉 포인터값이 복사된다,
